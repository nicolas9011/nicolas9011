## 📌 Proyectos Destacados

| Proyecto | Descripción | Tecnologías Clave |
| :--- | :--- | :--- |
| 📍 **[Movanza](https://movanza.site/)** *(Ex-ManiRuta)* | Plataforma SaaS B2B (co-fundada junto a Juan Fernando Parra) que transforma desplazamientos y eventos de campo en métricas útiles: geocercas, tiempos de permanencia, paneles administrativos y seguimiento en vivo sin vigilancia invasiva 24/7[cite: 3, 5, 11]. | `JavaScript` `Supabase` `Leaflet` `HTML/CSS` |
| 🦆 **DuckFlow** | Aplicación web interactiva para estudiantes universitarios enfocada en la gestión de tareas, horarios, seguimiento de materias y visualización de progreso académico. | `JavaScript` `Supabase` `HTML5` `CSS3` |
| 🌾 **AgroPrecios CO** | Arquitectura de ingeniería de datos y *pipeline* para ingerir, limpiar, transformar y visualizar los datasets públicos de precios mayoristas agrícolas (SIPSA - DANE). | `Python` `SQL` `Data Pipelines` |
| 🏦 **Simulación Transaccional (Banco Andino)** | Laboratorio de alto volumen en PostgreSQL: generación automatizada de **1 millón de transacciones** en 50,000 cuentas mediante scripts en Python y validación de integridad contable de partida doble en pgAdmin. | `PostgreSQL` `Python` `pgAdmin` |
| 🤖 **Benchmarking de LLMs Locales** | Evaluación de consumo de hardware, velocidad de inferencia e integración por API local de modelos como `llama3.2:3b` y `qwen2.5-coder:1.5b`. | `Python` `Ollama` `LM Studio` |
| 📡 **Ingeniería RF & Electrónica** | Simulación de radioenlaces en la banda de 900 MHz con modelos de elevación en RadioMobile/Google Earth, además de sistemas de control vehicular y análisis de circuitos. | `RadioMobile` `Cisco` `Arduino` |
